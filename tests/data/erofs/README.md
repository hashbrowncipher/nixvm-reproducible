# EROFS reader fixtures

These images were generated by the independent `mkfs.erofs` from erofs-utils
1.9 and checked with `fsck.erofs --extract`. They contain only synthetic data.
The tests read these files directly and need no installed EROFS tools.

Regenerate from the source tree and metadata declared in
`scripts/make-erofs-fixtures.py`:

```sh
python3 scripts/make-erofs-fixtures.py
```

The script fixes the block size to 4096, the UUID, uid/gid and timestamps, and
uses one worker. `base.erofs` is uncompressed; the four named codec images
contain the same tree. `middle.erofs` and `top.erofs` test native overlayfs
whiteouts, opaque directories and file/directory replacement across layers.

`reproducible.erofs` contains synthetic x86-64 programs for empty stdin,
terminal isolation, fork contention, flags, virtual time and output failures.
Regenerate it separately with `python3 scripts/make-reproducibility-fixture.py`.
The generator declares every byte and fixes image metadata. The `/fault` and
`/exit125` programs check the separation of guest outcomes from host failures.
