# Merge PMU scheduling with instruction interception

Resolved the pending merge of `nixvm-pmu` into `master`. Kept EROFS documentation,
instruction decoding, and PMU scheduling. Wall-clock mode keeps one budget across
internal KVM exits; PMU mode keeps its branch budget across those exits. Updated
two exception-recovery tests for the new vCPU constructor argument.

Fixed short execution charges rounding to zero at negative nice levels. Weighted
charges round up so a syscall loop advances virtual runtime. The regression
failed first at nice -20 with zero retired branches, then passed after the fix.
It covers zero and one branch at every nice level.

Validation ran offline with the unchanged Cargo.lock. The public registry caches
from the earlier CPUID and EROFS work were combined in `target/cargo-home`.
The parent test and landing helpers assume a root package.json and fail here.
The full suite used the existing in-process `layout.packages` adapter documented
in the EROFS worklog. Formatting used the documented root-crate ownership adapter.
No parent helper was changed.

- Full sealed `cargo test --offline --locked --features erofs,fstool --quiet`:
  passed, including 753 library tests and the integration and documentation tests.
  Two existing library tests and three explicit PMU hardware tests were ignored.
- Sealed `cargo test --offline --locked --test pmu -- --ignored --test-threads=1`:

  passed.

An extra hardware probe found a separate PMU limitation: guest PUSHFQ can expose
the host stepping TF bit, while the cached vCPU flags remain clear. Removing all
timestamp instructions from the probe still reproduces it. The committed
timestamp regression checks branch counts and cached flags; guest PUSHFQ
visibility remains open. To replay, put this test in a temporary integration test
file and run it through the seal with `cargo test --offline --locked --test NAME`:

```rust
use nixvm::vcpu::{Backend, Exit, GuestMemory, Prot, kvm::KvmBackend};

#[test]
fn pushfq_observes_host_stepping() {
    let backend = KvmBackend::with_branch_quantum(16).unwrap();
    let mut memory = GuestMemory::new(0x10000, 64 * 1024);
    memory.map(0x10000, 4096, Prot::rx()).unwrap();
    memory.map(0x17000, 4096, Prot::rw()).unwrap();
    // INC RBX; PUSHFQ; POP RSI; TEST RBX,RBX; JNZ start.
    memory.write_init(0x10000, &[
        0x48, 0xff, 0xc3, 0x9c, 0x5e, 0x48, 0x85, 0xdb, 0x75, 0xf6,
    ]).unwrap();
    memory.write_init(0x17ff8, &[0; 8]).unwrap();
    let mut cpu = backend.new_vcpu(0x10000, 0x18000).unwrap();
    cpu.begin_slice();
    assert_eq!(cpu.run(&mut memory).unwrap(), Exit::Interrupted);
    assert_eq!(cpu.rflags() & 0x100, 0); // passes
    assert_eq!(cpu.reg(6) & 0x100, 0); // fails: observed 0x100
}
```
